Test Automation Intern (Industry-Academia Co-op)

Sunbird Software Inc., Taiwan Branch · via the Software Security Lab, National Taipei University of Technology

2023 – Aug 2024

I wrote automated tests for an enterprise data-center infrastructure management platform. It was the kind of place where hundreds of end-to-end suites run in parallel against one live server overnight, and a single flaky test can cost the whole team a morning. It began as an industry-academia co-op through my university's Software Security Lab and continued as a full-time on-site internship, and it is where I learned that a test suite is something you maintain, not something you finish.

  • Turned ticket-level requirement specs into end-to-end suites, composing them from a shared library of several thousand reusable keywords and setting up test state through a REST API instead of slow UI flows.
  • Cleared the same merge gate every time: zero warnings from a custom lint rule set, ten clean runs back to back, then more with the network deliberately throttled.
  • Ran API load sweeps with JMeter and fed the results into the team's Python-to-Excel reporting pipeline.
  • Worked the team's real engineering cycle throughout, with Scrum ceremonies, code review, and release deadlines.
