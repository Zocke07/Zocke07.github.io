About

I grew up in Indonesia and moved to Taipei in 2021 for university. The degree was taught in Chinese. I picked the language up as I went, and I have studied and worked in it ever since.

Before any of that I was a math kid, and the part I liked was that you could check the answer. That is close to how I like to build software: I'd rather find out early that I'm wrong, while being wrong is still cheap.

I spent a good part of university outside class, on student organizations, volunteering and cultural exchange, including the Taipei Tech International Student Association. Mostly that meant helping international students settle into a place I had arrived at not long before myself.

Test Automation Intern (Industry-Academia Co-op)

Sunbird Software Inc., Taiwan Branch · via the Software Security Lab, National Taipei University of Technology

Jul 2023 – Dec 2024

I wrote automated tests for an enterprise data-center infrastructure management platform. It was the kind of place where hundreds of end-to-end suites run in parallel against one live server overnight, and a single flaky test can cost the whole team a morning. I worked it for a year and a half as an industry-academia co-op based in my university's Software Security Lab, with the summer of 2024 spent embedded full-time in the company's own office, and it is where I learned that a test suite is something you maintain, not something you finish.

  • Turned ticket-level requirement specs into end-to-end suites, composing them from a shared library of several thousand reusable keywords and setting up test state through a REST API instead of slow UI flows.
  • Cleared the same merge gate every time: zero warnings from a custom lint rule set, ten clean runs back to back, then five more with the network deliberately throttled.
  • Wrote tests that stay safe under parallel execution, declaring the shared subsystems each suite touches so hundreds of suites can run against one live server without colliding.
  • Worked the team's real engineering cycle throughout, with Scrum ceremonies, code review, and release deadlines.

The Defense That Says Where It Breaks
