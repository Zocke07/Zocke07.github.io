自動化測試實習生（產學合作）

Sunbird Software Inc. 臺灣分公司 · 經由國立臺北科技大學軟體安全實驗室

2023 – 2024 年 8 月

我為一套企業級資料中心基礎設施管理平台撰寫自動化測試。在那裡，數百組端對端 測試會在夜間平行跑在同一台線上伺服器上，只要有一個測試不穩定，就可能讓整個 團隊損失一個上午。這份工作最初是透過學校軟體安全實驗室的產學合作開始，後來 延續為全職駐點實習；也是在這裡，我學到測試套件是需要長期維護的東西，而不是 做完就結束的東西。

  • 把 ticket 層級的需求規格轉成端對端測試套件，以共用函式庫中數千個可重用的關鍵字組合而成，並改用 REST API 建立測試狀態，取代緩慢的 UI 操作流程。
  • 每一次合併都通過同一道關卡：自訂 lint 規則零警告、連續十次執行全數通過，接著再刻意限制網路頻寬多跑幾輪。
  • 撰寫能安全平行執行的測試：明確宣告每個套件會動到的共用子系統，讓數百組套件同時跑在同一台線上伺服器上而不互相干擾。
  • 全程參與團隊真實的開發節奏，包含 Scrum 會議、程式碼審查與發布期限。
