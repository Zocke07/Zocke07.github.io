大學生活不是只有課堂。我把不少時間投入學生社團、志工服務與文化交流，包括北科大國際學生會；其中很多是陪剛到臺灣的國際學生適應環境，而當時我自己也才剛適應不久。

自動化測試實習生（產學合作）

Sunbird Software Inc. 臺灣分公司 · 經由國立臺北科技大學軟體安全實驗室

2023 年 7 月 – 2024 年 12 月

我為一套企業級資料中心基礎設施管理平台撰寫自動化測試。在那裡，數百組端對端測試會在夜間平行跑在同一台線上伺服器上，只要有一個測試不穩定，就可能讓整個團隊損失一個上午。這份產學合作我以學校軟體安全實驗室為據點參與了一年半，其中 2024 年 7 到 8 月以全職實習生身分進駐公司辦公室；也是在這裡，我學到測試套件是需要長期維護的東西，而不是做完就結束的東西。

  • 把 ticket 層級的需求規格轉成端對端測試套件，以共用函式庫中數千個可重用的關鍵字組合而成，並改用 REST API 建立測試狀態，取代緩慢的 UI 操作流程。
  • 每一次合併都通過同一道關卡：自訂 lint 規則零警告、連續十次執行全數通過，接著再刻意限制網路頻寬多跑五次。
  • 撰寫能安全平行執行的測試：明確宣告每個套件會動到的共用子系統，讓數百組套件同時跑在同一台線上伺服器上而不互相干擾。
  • 全程參與團隊真實的開發節奏，包含 Scrum 會議、程式碼審查與發布期限。

說得出自己何時失效的防禦

碩士論文 · 聯邦式學習安全

聯邦式學習把原始資料留在裝置上，但這也表示伺服器分不出一筆模型更新是遭到毒化，還是誠實的。我的論文提出 L-MAD，一套兩階段的防禦機制：單獨拒斥被汙染的層，而不是丟掉整個用戶端。在 30% 毒化攻擊下，它的 DDoS 類別 F₁ 維持在 97.5%，領先六個重新實作的基準方法 25 個百分點以上，而最後一章是特地設計來推翻我自己最弱的主張。

從真值表到管線化 CPU

大學部課程 · VHDL / FPGA · 嵌入式 Linux

兩個學期的硬體實習課程。前一個學期在 FPGA 上以 VHDL 由下往上堆疊：先從真值表推導出七段顯示器解碼電路，再用一位元全加器組出多位元加法器，接著是 ALU、移位暫存器、狀態機、還原式除法器，最後是一顆四階管線化 CPU，能偵測仍在管線中的指令之間的 RAW 資料危障，並把運算結果前饋回去，而不是插入停頓。後一個學期則在 NVIDIA Jetson TX2 上一層層往下走：從跨平台編譯的 C++ 執行檔透過 Linux sysfs 控制腳位，經過 Qt GUI 與以瀏覽器操作的 Node.js 伺服器，一直到自己寫的可載入核心模組，註冊字元裝置，讓使用者空間改以寫入 /dev 的方式操作硬體。三人合作的期末專案把這些串成一個房間管理面板：伺服器載入模組、對裝置節點寫入指令、在工作執行緒上讓計時燈號閃爍，並透過自己打時脈的 SPI 迴圈輪詢光敏電阻。這些是實習作業而不是產品，但也是我知道上層軟體究竟站在什麼東西上面的原因。
